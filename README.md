# Maccabi Penalty Shootout

A two-player penalty shootout in Maccabi Tel Aviv yellow and blue, for playing at home.

- Upload a photo for each player; the faces go on the shooter and the keeper.
- The shooter picks left, middle or right, the keeper picks where to dive, then the kick plays out.
- Five kicks each, then sudden death.

Everything is in `index.html` — no build step. Open it in a browser, or serve it with GitHub Pages.
Photos and names are saved only in the browser on the device you use.

Works on phones in portrait and landscape. Laptop keys: shooter `A` `S` `D`, keeper `J` `K` `L` or the arrow keys.
